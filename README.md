# Undertow Studio

Apps and an operating system made by Brayden.

- **Cobalt**: blue Material 3 productivity app (tasks, alarms, focus timer, StandBy mode, widgets)
- **Tide**: minimal list-style Android launcher
- **Swell**: clean, free music player for the songs on your phone (share audio to it or pick files)
- **Lumen**: pro camera for Pixel 5+ and Galaxy S20+ (15 modes, RAW, LOG, 4K HDR, horizon lock, live filters, widgets)
- **Nava OS**: frosted-glass Arch Linux + Hyprland desktop OS (download from Releases)

Website: https://1tekno4884-sketch.github.io/undertow-studio/

## ⚠️ Never remove `google4181ba9e057dbe17.html`

That file proves to Google Search Console that this site belongs to Brayden. Google
re-checks it from time to time: if it's deleted, renamed or edited, the site loses its
verification. Leave it exactly as it is, and don't link to it from the pages or add it to
`sitemap.xml` (it's meant to stay unlisted).

## Version archive (`archive.html`, `archive/`)

Started 21 Nov 2026. When an app is updated, **move the previous APK into `archive/`** as
`<App>-<version>.apk` (e.g. `git mv Lumen.apk archive/Lumen-1.5.apk`) before copying the new one in,
then add a row for it to that app's list in `archive.html` (newest first) and bump the "Current" row.
